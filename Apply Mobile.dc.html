Decisions I made

The desktop tool asked for your history on every run. On a phone that's fatal, so the background moves into the profile and the per-application screen shrinks to two inputs: the posting and a tone. Capture leads with clipboard and camera, because a posting on a phone is almost always in another app.

Auto-apply

Handshake sync lists matching openings with a match score; you pick which ones and start once. Each application is tailored separately — the queue shows a per-job state rather than one bar, so a bulk action still reads as individual work.

The URL field takes any careers page or job board so the same treatment covers postings Handshake doesn't carry. One guardrail kept: you review every draft before it sends.

Three resume designs

The Resume tab now carries a design picker. All three hold one page and print to the same content, so switching never loses a line.

Ruled — ruled section heads, single column. The safe one for applicant tracking systems.
Column — sage sidebar holds contact and skills so the right column is nothing but evidence.
Editorial — display name at full size, skills as pills. For design and brand roles.
Free, stated plainly

No paywall screen, no locked tab. The one line under the main action carries it: unlimited runs, free, powered by Claude.

Sounding human

The drafts are written the way a person writes: contractions, short sentences, one specific number per claim, no throat-clearing openers and no stock phrases. The Plain words switch on step 2 governs it, and the Documents screen reports what it caught.

Generation is still a scripted mock. Say the word and I'll wire real Claude calls behind the same screens.
